# Bullasゲーム自動収集スクリプト

Bullasゲームのクレーム機能を自動的に定期的に実行し、ゲームの報酬を収集します。

## 機能

- 一定間隔（デフォルト8時間）で自動的に報酬を請求。
- スマートコントラクトと直接連動し、ブラウザのエミュレーションは必要ありません。
- シンプル、軽量、安定、信頼性
- 各報酬収集時間のログを記録し、すぐに実行する必要があるかどうかを自動的に判断。

## インストールと使用

1.依存関係をインストールする。
``bash
npm install ethers@5.7.2 dotenv
``

2.envファイルを設定する。
```
RPC_URL=https://rpc.berachain.com
PRIVATE_KEY=your_private_key_here
# Bullas V2
GAME_CONTRACT_ADDRESS=your_game_CA
TOKEN_ID=あなたのtoken_id
CHECK_INTERVAL=28800 # インターバル時間（秒、デフォルトは8時間
``

3.スクリプトを実行する。
``bash
ノード index.js
```

## 動作原理

1.起動時に最後の実行履歴を読み、即座に実行するか待機するかを決定する。
2.ウォレットとコントラクト間の接続を初期化する。
3.スマートコントラクトのクレーム関数を直接呼び出し、報酬を受け取る。
4.実行時間をログファイルに記録する。
5.設定した間隔で定期的に実行を繰り返す。

## ログファイル

スクリプトは成功した各実行の時間を `claim_log.txt` ファイルに記録する。書式は以下の通りである：
``
2023-10-25T08:00:00.123Z - TokenIDのクレームが実行されました: 1699
```

スクリプトが再起動されると、このログファイルが読み込まれ、クレーム処理を直ちに実行する必要があるかどうかが判断される：
- ログファイルが存在しないか空の場合、スクリプトは直ちに実行されます。
- ログファイルが存在しないか空の場合、スクリプトは即座に実行される: 最終実行時刻 + 間隔 > 現在時刻の場合、スクリプトは実行されるまで待機する。
- 最終実行時刻＋インターバル＞現在時刻の場合、実行されるまで待つ。

## 最終実行時刻＋インターバル時間＞現在時刻の場合、実行されるまで待つ。

- 秘密鍵を共有しない
- ウォレットにGasの支払いに十分なBERAがあることを確認する！
- ログファイル(`claim_log.txt`)はスクリプトと同じディレクトリにあります。

## はじめに

### 前提条件

- Node.js (バージョン14以上)
- Berachainウェブウォレット（秘密鍵付き）
- ゲーム契約アドレス

### インストール

1.このリポジトリをクローンするか、ソースコードをダウンロードする。
2.プロジェクトディレクトリに移動し、依存関係をインストールします：

bash
cd auto_claim
npm install
``

3.サンプルの環境変数ファイルをコピーして、環境変数を設定します：

bash
cp .env.example .env
``

4.作成した `.env` ファイルを編集し、以下の情報を入力する：
   - RPC_URL``: Berachain RPC URL
   - ``PRIVATE_KEY``: ウォレットの秘密鍵 (秘密にしてください！)
   - GAME_CONTRACT_ADDRESS`: ゲーム契約アドレス
   - CHECK_INTERVAL`: チェック頻度 (秒単位)

### 使用方法

1.envファイルが正しく設定されていることを確認する。
2.スクリプトを実行する：

bash
ノード index.js
``

このスクリプトはアカウントの容量状況を監視し始め、容量がいっぱいになると自動的に報酬を集めます。

## よくある質問

**Q: ゲーム契約アドレスはどこにありますか？**

A: .env.example にあります。

**Q: スクリプトがネットワークに接続できないのはなぜですか？**

A: RPC URLが正しいか、またBerachainネットワークが正常に動作しているか確認してください。

**Q: スクリプトが正しく動作していることを確認するにはどうすればよいですか？**

A: スクリプトは、容量ステータスやトランザクションハッシュを含むログメッセージを出力します。トランザクションが成功したかどうかは、Berachain Block Browserで確認できます。
